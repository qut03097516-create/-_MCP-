## 直接支持的事实

- PR（性能比）= 实际产量/参考产量，IEC 61724-1:2021 定义两种温度修正 PR（25 ℃ PR 与年温度等效 PR）
- 高 DC:AC 比系统中逆变器截断使标准 PR 出现季节与年际波动；行业常用做法是剔除截断时段数据，但会偏置剩余数据集
- 提出 CCPR：用截断修正辐照度（G_CC）替换 POA 辐照度，无需截断检测算法
- 仿真方法：MATLAB + PV_LIB + Bifacial_radiance，6 个 BSRN 站点 1 分钟实测数据，DC:AC 比 0.89–1.6

### 关键结果

- 日照最充足站点（IZA）DC:AC=1.6 固定倾角单面阵列约 65% 发电量产生于截断状态；单轴跟踪最高约 85%
- TCPR 在 DC:AC 从 1.0 升至 1.6 时由 94% 降至 73%（IZA 极端情形）
- 年际变率：DC:AC=1.6 时温度修正 PR 年际变率 0.59%，加截断修正（CCPR）后降至 0.15%
- 年度准确度：TCPR 2.68% vs CCPR 0.27%；CCPR 阈值设为「预期下方约 1%」可 100% 捕获故障且无误报
- 用 1 h 分辨率 TMY/历史数据建模会让高 DC:AC 系统预期产量/PR 高估约 4%

## 限制条件

- 全文基于合成（仿真）数据：无衰减、积灰、遮挡、组件不一致
- 未包含测量不确定度与数据质量问题
- CCPR 不宜单独用于性能衰减率（PLR）分析，应与 TCPR 配合使用

## 不能推出的结论

- 不能直接推出中国电站的 PR 验收值（本文为指标方法论，非规定值）
- 不能推出组件衰减率或 PR 损失的绝对数值适用于具体电站
- 不能推出标准 PR 完全错误（截断修正与温度修正互补）
