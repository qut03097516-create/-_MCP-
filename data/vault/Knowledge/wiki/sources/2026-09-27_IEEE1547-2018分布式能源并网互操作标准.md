# IEEE Std 1547-2018 分布式能源资源并网互连与互操作标准

| 字段 | 值 |
|---|---|
| 标准号/版本 | IEEE Std 1547-2018 |
| 全称 | IEEE Standard for Interconnection and Interoperability of Distributed Energy Resources with Associated Electric Power Systems Interfaces |
| 类型 | IEEE 标准 |
| 状态 | 现行，有效期至 2028；P1547 修订组已启动后续修订（2023 起） |
| 发布机构 | IEEE（经 SCC21 制定） |
| 取代 | IEEE Std 1547-2003 |
| 修订件 | IEEE Std 1547a-2020（增加异常运行性能类别 III 灵活性，兼容至 2032） |
| 配套 | IEEE Std 1547.2-2023（应用指南） |
| 来源 | [IEEE SCC21](https://sagroups.ieee.org/scc21/ieee-1547-series/) |

## 核心内容

- 建立分布式能源资源（DER）与电力系统（EPS）并网互连与互操作的标准与要求，涵盖接口技术规格与试验。
- 北美分布式电源（含分布式光伏、储能）并网的主要技术依据，被美国 2005 能源政策法案引用。
- 系列含 1547a（修订）、1547.1（互连测试）、1547.2（应用指南）等配套文档。
