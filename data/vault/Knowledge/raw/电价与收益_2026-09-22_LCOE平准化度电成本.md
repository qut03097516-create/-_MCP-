# LCOE（平准化度电成本）：定义、计算所需数据与局限

**来源**：见下方各节原始链接
**整理时间**：2026-09-22
**主题**：电价与收益
**适用场景**：光伏及其他发电技术成本比较、项目经济性评估

## 一、官方定义

### 1. 美国能源信息署（EIA）官方术语表定义

> **Levelized cost (平准化成本)**：发电厂在其**经济寿命期**内建造和运行总成本的**现值**，转换为**等额年度付款**。成本以实际美元（扣除通胀影响）平准化。

链接（EIA Glossary，官方权威）：https://www.eia.gov/tools/glossary/index.php?id=levelized_cost

### 2. EIA Today in Energy 对 LCOE 的展开解释（2020-03-06）

LCOE 代表电厂的**安装资本成本**（含建设、融资成本、税收抵免及其他补贴/税费）与**运行成本**（燃料、预期维护费用、运行相关税费/补贴），折算为在电厂假定的**财务寿命期**内的等额付款流。

与之配套的 **LACE（平准化避免成本）** 代表电厂对电网的**价值**——通过替代另一边际机组所避免购电成本的估计收入。EIA 强调：**LCOE（成本）与 LACE（价值）应配合使用**，LACE/LCOE 比值 >1 时项目被认为具有经济吸引力；仅用 LCOE 不足以判断技术竞争力（如光伏 LACE 因白天市场饱和而下降，但 LCOE 下降更快，二者需结合）。

链接（官方全文）：https://www.eia.gov/todayinenergy/detail.php?id=43095

### 3. OECD / IRENA 方法学定义（2022）

> LCOE 表示项目寿命期内**每单位发电量所对应的折现成本之和**。LCOE 亦可定义为：在支付资本要求的必要回报率后，投资者恰好**盈亏平衡**时的电价。

计算公式（最基本形式）：

`LCOE = Σ_t (I_t + M_t + F_t) / (1+r)^t ÷ Σ_t E_t / (1+r)^t`

其中：I = 投资支出、M = 运维支出、F = 燃料支出（光伏为 0）、E = 年度发电量、r = 折现率、t = 年份。

链接（OECD 官方页面）：https://www.oecd.org/en/publications/measuring-natural-resources-in-the-national-accounts_420c7c2a-en/full-report/the-levelised-cost-of-electricity-method_31cd8dbd.html

## 二、计算所需数据

| 输入项 | 说明 |
| --- | --- |
| 初始投资成本（CAPEX） | 设备、安装、并网、前期开发费用；含融资成本与税收抵免（EIA 口径） |
| 运维成本（OPEX） | 运行与维护、保险、场地租金等 |
| 燃料成本 | 光伏/风电为 0；火电/气电需计入 |
| 年度发电量 E(t) | 装机 × 等效利用小时数（辐照/容量因子驱动），逐年输入 |
| 折现率 r（WACC） | 一般取资本加权平均成本；国际机构常用 5%-10%（发达市场）、更高（新兴市场） |
| 经济/财务寿命期 | 光伏通常按 20-30 年（EIA/IRENA 常用 25 年量级；具体以模型设定为准） |
| 其他 | 退役/拆除成本（如有）、通胀假设（实际 vs 名义口径） |

## 三、局限与应用注意（综合官方/权威来源）

1. **成本指标而非价值指标**（EIA）：LCOE 只回答"度电成本多少"，不回答"发出来的电值多少钱"。光伏在午间集中出力时段市场价值低（EIA 解释光伏 LACE 随市场饱和下降），需与价值指标（LACE、时段价值、省去容量成本）配合；
2. **不体现能源的时空价值**（OECD/NREL 等研究提及）：LCOE 假设所有电量等值，不反映不同地点/不同时间的价值差异，跨区域比较或高渗透率场景下会误导；
3. **对折现率与寿命假设敏感**：资本密集型技术（光伏、核电）对 r 极其敏感，r 取值不同结论可能反转，比较时必须统一假设；
4. **不含系统层面的外部成本/收益**：并网成本、消纳成本、环境与补贴等通常未计入，属于"厂内成本"口径；
5. **用于横向比较的注意**：不同机构（IRENA/Lazard/EIA/IEA）因口径（是否含融资、税、退役、地区差异）不同，LCOE 数值不可直接跨来源比较。

> 对光伏项目，业界（IRENA 2023、Lazard 等）普遍计量到"光伏 LCOE 已降至化石能源以下"的结论，但 EIA 方法论强调必须同时看价值侧，本知识库不替代专业投资决策。
